# 站点路线图（Roadmap）

记录时间：2026-11-26

## 主线：一条人口链

```
结婚（当年）
  └→ 出生（滞后约 1 年）
       └→ 幼儿园 / 小学（滞后 6 年）
            └→ 劳动力（滞后 20 年）
                 └→ 养老（滞后 60 年）
```

站点按这条链组织：**首页讲整条链，子页面各管一段**。
当前版本先落两段：结婚（最新、最靠前）+ 人口结构（最长、最全）。

## 当前版本页面

| 路由 | 角色 | 内容 |
| --- | --- | --- |
| `/` | 门面 | 报告式首页，给大众看，6 屏，冻结图，末尾分流到子页面 |
| `/population` | 工具 | 原人口结构仪表盘（年龄金字塔、播放器、情景、消费热点） |
| `/marriage` | 工具 | 结婚趋势明细（年度、季度、省份、离结比） |

README 同步改成封面式（大图 + 一句话 + 三个入口）。

## 原则（避免以后越加越乱）

1. 一个页面 = 链上一段，不重复讲同一件事。
2. 首页永远只做"钩子 + 分流"，不做全量数据。
3. 新页面必须先有可信数据源，再谈图表。
4. 口径写死在页面上（1 对 = 2 人、离结比 = 对数÷对数、季度非累计）。
